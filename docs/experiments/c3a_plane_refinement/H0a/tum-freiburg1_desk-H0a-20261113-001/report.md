# H0a 기준선·수식 검증

H0의 합성 층 offset 0.6%는 고정 inlier 0.5% 밖인데 공유 적합 성공을 기대한 제어 오류였다. 원래 실패를 보존하고 offset 0.3%로 수정한 H0a에서 전체 검증을 다시 실행했다. 실제 데이터 임계값은 바꾸지 않았다.

C3a proposed를 기준으로 589,824개 관측을 재현했다. 광선-평면 hard 교차, soft 해와 독립 수치 최소화, 자기 재투영, RGB/ID/K/pose/점 수·거절점 불변 검사를 통과했다.

평행 벽·모서리·곡면·가림·단일 프레임·선형 지지·스침각·음의 깊이·2% 경계 합성 제어를 확인했다. 독립 평면의 층 간격은 남고 공유 평면의 층은 줄었다. 이는 수식 제어이며 실제 정답 벽 복구의 증거가 아니다.

RANSAC은 고정 seed의 최대 4,096 fit 점으로 가설을 채점한 후 전체 fit 점에서 최종 지원과 IRLS를 평가한다. 적응적 반복 종료의 최소는 64, 최대는 2,000이다. 고유값 비 1e-4/두 번째 축 범위 1%의 퇴화 기준을 실험 전에 고정했다.
