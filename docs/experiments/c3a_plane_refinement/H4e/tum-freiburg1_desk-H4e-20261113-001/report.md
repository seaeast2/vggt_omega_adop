# H4e 공유 평면 범위 확장·이동/법선 허용 완화

기존 H4d A4의 공유 월드 평면 하나를 그대로 고정하고 원래 C3a에서 각 군을 독립 시작했다. 평면의 추정·계수·카메라·RGB·점 수는 바꾸지 않았다. 기존 소속 고정 3군은 이동 한도만, 확장 9군은 같은 소속 정의에서 점 법선 각도와 이동 한도를 비교한다. 기존 2% 제한만으로 거절된 점은 15개였으므로 후보 소속 확장 효과를 분리해야 했다.

기존 15°는 후보 평면 간 association 기준이었다. 이번 15/25/35°는 모든 프레임의 개별 7×7 법선과 고정 공유 평면의 각도다. 기존 법선 K-means cluster를 합치는 설정으로 해석하지 않는다. 확정된 camera0/1 원시 NMS 벽 범위에 교차점이 투영되고 참조 깊이 3% 확인을 통과한 점을 모든 프레임에서 재판정한다. 원래 refined mask/cluster 밖도 허용하지만 무한 평면 전체를 대상으로 하지 않는다. 자기 프레임 RGB mask는 필수 조건이 아니며 원래 mask 밖 변화도 별도로 센다.

음수는 C3a 대비 두께/해당 지표 감소다. 층 간격은 다른 패치를 가진 source median 차이이며 평면화 자체와 다를 수 있다. 모든 수용점은 같은 평면 위에 있지만 거절·경계·비대상점은 남는다. 소속이 넓어져 기존 RGB non_target ROI의 일부가 움직일 수 있고 이를 고정 ROI별 지표와 마스크로 공개했다. 0/1의 공유 벽에 대한 참조만 있어 frame2는 평가 대상에 포함해도 실제 수용이 없을 수 있다. 물체 경계의 과보정 가능성을 GT 없이 배제하지 않는다.

평면 0.5% fit inlier·15° association·confidence 하위10% 제외·영상8px border·참조 마스크 erosion3px·참조 가림깊이3%·스침각 cos0.2는 이번에 완화하지 않았다. 이동 한도와 법선 소속 gate 외 제약을 명시적으로 유지했다. 각 군에서 가시성 보존 기준 실패 시 retained=A0이며 실제 proposed는 보존한다. GPU/모델 재추론은 없었다.

원래 2%군의 XYZ/accepted bitwise 재현, 이동/각도 완화 시 수용 집합의 단조 증가, 공통 수용점 XYZ 동일, 한 평면 잔차<1e-10, 거절점 bitwise 보존·PLY 왕복·자기 재투영·입력 해시 검사를 통과했다. 실제 정확도/보편적 최적 threshold는 확정하지 않았다.
