# H2 후보·평가 분리 동결

7×7 PCA 법선, 원본 confidence 하위 10% 제외, 3 px 마스크 erosion과 독립 8 px 영상 border를 적용했다. seed 0의 법선 K-means 5개/10회 및 연결 성분으로 원시 마스크를 분리했다. 21×21은 진단만 했다. 후보 최소 면적은 984 px다.

기하 전용 군은 7×7 이웃 그래프에서 법선 15°·양방향 국소 접평면 거리/원본 Z 0.5%로 생성했다. RGB에서 사전에 정한 벽 사각형 지지 100 px·후보 5% 이상 규칙으로 벽 후보를 표시했으며 영상 마스크는 생성에 사용하지 않았다. 이 검토 규칙과 모든 기하 영역의 수용/제외를 보존했다.

16×12 타일 SHA256으로 fit/holdout을 고정하고, 알려진 보류 track 관측 3 px 주변을 추가로 fit에서 제외했다. 중복 후보 관측은 모호로 제외한다. 벽/경계/비대상 ROI를 보정 결과 생성 전에 고정했다. 기존 G6 벽 ROI와 새 RGB 사각형 ROI를 구분했다. 정답 분할 없이 정확도라고 부르지 않는다.
