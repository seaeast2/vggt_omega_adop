# H6 C3a 기준 영상 분할·평면 보정 종합 결과

H0~H6 실행과 보조 검증을 완료했다. **실행 완료와 정확도 개선 입증을 구분한다.** C3a 실제 FoV proposed를 고정하고 589,824점의 ID·순서·픽셀색·K·pose를 보존했다. 점은 자기 픽셀 광선의 Z 방향으로만 최대 2% 이동한다.

H0의 합성 지원 오류는 H0a로 보완했다. H2/H2b의 알려진 track 45개 중 10개가 타일 경계로 양쪽 split에 걸린 것을 추가 audit에서 발견했다. 원래 보류 matching track은 모든 실행에서 fit 제외였지만, 전체 track 분리 계약을 만족하지 않아 **H2c(기본)/H2d(NMS)에서 track 전체 holdout으로 수정하고 H3c~H5c / H3d~H5d를 재실행**했다. 최종 두 split은 mixed=0이다. 기존 결과는 비교용 이력으로 보존한다.

기본 마스크는 camera0/1에서 겹쳐 모호한 벽 지지가 대부분 제외된다. 기본 공유군은 연결 조건을 통과하지 못했다. 보조 NMS는 SAM predicted-IoU 높은 후보부터 mask IoU>0.5 중복을 제거하며 원본 H1 마스크를 수정하지 않는다. 최종 NMS 공유군은 camera0/1의 벽 하나를 연결했다. camera2를 같은 공유 벽의 지지로 주장하지 않는다.

음수는 해당 오차/두께 감소다. 벽 기준 평면과 관측 ID는 G6와 같은 A0 참조이며 camera0/1만 지지한다. 서로 다른 공간 패치를 가진 source의 signed median은 공유 평면에 모여도 변할 수 있다. 층 간격·두께를 함께 보고, 적합 평면 잔차가 0이 되는 현상을 정확도 증거로 쓰지 않는다. 보정 후 육안 품질을 이 수치만으로 단정하지 않는다.

기하 전용 region growing은 camera0에서 국소 인접 그래프가 책상·벽까지 연쇄 연결된 큰 후보를 만들었고 최종 robust 70% 지지 조건에서 거절됐다. camera2 후보도 지원 부족이다. A6에는 공유 보정이 없으므로 A4/A6 수용 관측 교집합은 비어 있다. 이 결과는 영상 분할의 보편적 우위를 뜻하지 않는다.

자동 RGB 검토: camera0의 넓은 두 번째 SAM 마스크는 책상 일부까지 포함한다. camera1에는 중복 벽 마스크가 있고, camera2는 다른 벽/물체 주변이 일부 섞인다. NMS 후의 camera0/1 오버레이는 벽 영역을 더 잘 보존하지만 정답 annotation 기반 평가는 아니다. 법선 정제로 좁은 성분이 생기며 적용 면적도 달라진다. 새 RGB ROI·경계·비대상 이동 수는 개별 군 metrics에 있다.

모든 최종 군의 배열·두 색상 PLY를 다시 읽어 점 수/좌표/색/출처를 검증했다. 거절/비대상은 bitwise 유지한다. frustum 관측 유지와 실제 pixel coverage를 별도로 평가했고, retained는 보존 통과 시 proposed를 가리킨다. 제안값이 A0와 같으면 그대로 표시한다. H5c/H5d는 해당 H4의 평면·목표·gate와 정확히 같다.

투영은 원본 입력과 같은 512×384, 같은 nearest-pixel z-buffer/점 크기이며 RGB 학습·색 혼합 없이 원본 픽셀색을 쓴다. 전체/타 프레임/출처별 카메라 투영, 고정 외부 시점, 고정 범위 벽 단면, 수용 마스크를 보존했다. PLY 빠른 경로는 `results/c3a_plane_refinement/ply_review/`이며 **c=기본 최종, d=중복 마스크 NMS 보조 최종**이다. initial/proposed/retained와 RGB/frame_colors를 구분한다.

GT 동기·resize/K/pose·정렬을 이 실험에서 검증하지 않았으므로 실제 기하 정확도는 미평가다. 원래 보류 대응도 소수이며 벽은 텍스처가 적다. 보류 지표가 그대로여도 벽 개선의 독립 검증이 되지 않는다. 모델 설치/다운로드 시간은 별도 계측하지 않았으며 로딩·추론·기하 단계 시간과 process/GPU peak memory는 JSON에 기록했다. 공식 checkpoint SHA256, SAM 소스 commit, HF revision, 환경 변화도 보존했다.
