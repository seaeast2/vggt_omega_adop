# H6 C3a 기준 영상 분할·평면 보정 종합 결과

H0~H6 실행과 보조 검증을 완료했다. **실행 완료와 정확도 개선 입증을 구분한다.** C3a 실제 FoV proposed를 고정하고 589,824점의 ID·순서·픽셀색·K·pose를 보존했다. 점은 자기 픽셀 광선의 Z 방향으로만 최대 2% 이동한다.

H0의 합성 지원 오류는 H0a로 보완했다. H2/H2b의 알려진 track 45개 중 10개가 타일 경계로 양쪽 split에 걸린 것을 추가 audit에서 발견했다. 원래 보류 matching track은 모든 실행에서 fit 제외였지만, 전체 track 분리 계약을 만족하지 않아 **H2c(기본)/H2d(NMS)에서 track 전체 holdout으로 수정하고 H3c~H5c / H3d~H5d를 재실행**했다. 최종 두 split은 mixed=0이다. 기존 결과는 비교용 이력으로 보존한다.

기본 마스크는 camera0/1에서 겹쳐 모호한 벽 지지가 대부분 제외된다. 기본 공유군은 연결 조건을 통과하지 못했다. 보조 NMS는 SAM predicted-IoU 높은 후보부터 mask IoU>0.5 중복을 제거하며 원본 H1 마스크를 수정하지 않는다. 최종 NMS 공유군은 camera0/1의 벽 하나를 연결했다. camera2를 같은 공유 벽의 지지로 주장하지 않는다.

자동 RGB 검토: camera0의 넓은 두 번째 SAM 마스크는 책상 일부까지 포함한다. camera1에는 중복 벽 마스크가 있고, camera2는 다른 벽/물체 주변이 일부 섞인다. NMS 후의 camera0/1 오버레이는 벽 영역을 더 잘 보존하지만 정답 annotation 기반 평가는 아니다. 법선 정제로 좁은 성분이 생기며 적용 면적도 달라진다. 새 RGB ROI·경계·비대상 이동 수는 개별 군 metrics에 있다.

모든 최종 군의 배열·두 색상 PLY를 다시 읽어 점 수/좌표/색/출처를 검증했다. 거절/비대상은 bitwise 유지한다. frustum 관측 유지와 실제 pixel coverage를 별도로 평가했고, retained는 보존 통과 시 proposed를 가리킨다. 제안값이 A0와 같으면 그대로 표시한다. H5c/H5d는 해당 H4의 평면·목표·gate와 정확히 같다.

투영은 원본 입력과 같은 512×384, 같은 nearest-pixel z-buffer/점 크기이며 RGB 학습·색 혼합 없이 원본 픽셀색을 쓴다. 전체/타 프레임/출처별 카메라 투영, 고정 외부 시점, 고정 범위 벽 단면, 수용 마스크를 보존했다. PLY 빠른 경로는 `results/c3a_plane_refinement/ply_review/`이며 **c=기본 최종, d=중복 마스크 NMS 보조 최종**이다. initial/proposed/retained와 RGB/frame_colors를 구분한다.

GT 동기·resize/K/pose·정렬을 이 실험에서 검증하지 않았으므로 실제 기하 정확도는 미평가다. 원래 보류 대응도 소수이며 벽은 텍스처가 적다. 보류 지표가 그대로여도 벽 개선의 독립 검증이 되지 않는다. 모델 설치/다운로드 시간은 별도 계측하지 않았으며 로딩·추론·기하 단계 시간과 process/GPU peak memory는 JSON에 기록했다. 공식 checkpoint SHA256, SAM 소스 commit, HF revision, 환경 변화도 보존했다.

## H4e: 공유 평면 재소속과 제한 완화 (후속)

사용자의 후속 지시에 따라 같은 H4d A4 공유 평면을 고정하고 12개 군을 추가 실행했다. 이동 한도만 2→5→10%로 바꾸는 3군과, 모든 프레임에서 공유 평면 소속을 다시 판정하며 점 법선 15/25/35° × 이동 2/5/10%를 비교하는 9군이다. 기존 15°는 후보 평면 연결 각도였고 이번 각도는 각 점의 법선과 고정 평면 사이의 소속 gate라는 차이가 있다.

이 장면에서는 이동 상한보다 원래 cluster/마스크의 제한된 소속이 더 큰 병목이었다. 재소속 후에는 frame2도 같은 월드 평면으로 이동한다. 35°·5%군은 기존 소속 밖 24,858점을 보정했으며 5→10%의 추가 수용은 없다. 고정 벽 두께는 C3a 대비 약 21.28% 감소하고 source median 층 간격은 약 1.03% 증가했다. 기존 H4d A4의 +41.22% 층 간격과 다르지만, 이 값만으로 전체 기하 정확도 개선을 확정하지 않는다.

재소속은 원래 camera0/1의 NMS 원시 벽 영역에 평면 교차점이 투영되고 참조 깊이 3%를 만족하는 범위 안에서만 수행한다. 무한 평면의 모든 근접점에 적용하지 않는다. 영상 8px border·confidence 하위10% 제외·참조 erosion3px·스침각은 유지했다. 35°·5%군에서 고정 RGB 경계 ROI 249점과 non_target ROI 4점도 움직였으므로 물체 경계가 완벽히 보존됐다고 주장하지 않는다. 기존 벽 ROI에는 여전히 source0/1만 있으며 추가 source2 점은 다른 부분의 관측이다.

12군 모두 가시성 보존 조건과 수식·점 수·RGB·카메라·거절점 불변을 통과했다. 기존 2%군 bitwise 재현, 각도/이동 완화에 따른 소속 단조성, 공통 수용점 XYZ 동일성도 확인했다. GT 정확도는 미평가다. 원래 제안값은 모두 유지하고 최적 설정을 자동 선택하지 않았다.

## H4f: SAM 전체 소속 신뢰·이동 상한 제거

사용자의 지시에 따라 기존 H4e의 점 법선·confidence·경계 erosion·참조 깊이 3%·이동 한도 때문에 제외되던 벽을, H1 SAM 원본 마스크 전체에서 다시 선택했다. H1 RGB 검토 결과 camera1의 넓은 mask1은 H2d NMS에서 제외됐으며, 이 마스크를 주 군에서 복원했다. camera0은 벽 mask0 전체, camera1은 넓은 벽 mask1 전체를 사용한다. camera2는 mask0 중 그 평면이 camera0/1 벽 범위에 연결되는 부분을 사용하며 참조 depth는 확인하지 않는다. 카메라0/1에는 이 연결 gate도 없다.

이번 **SAM_SHARED_UNCAPPED**는 이동 상한·법선·신뢰도·영상/마스크 경계 제외 없이 같은 H4d A4 평면으로 정확히 재투영한다. 원본 광선에서 유한한 양의 교차 깊이와 수치 평행 방지 cos≥1e-8만 요구한다. 100% 초과 깊이 변화도 허용한다. 새로운 평면 추정이나 RGB 학습은 하지 않았다.

주 군에는 자기 깊이 변화 20% 초과 6,767점, 100% 초과 790점이 실제로 포함된다. 최대 상대 깊이 변화는 약 581.66%이며 camera1의 넓은 마스크 일부에서 발생했다. 이 값은 원래 예측 깊이에 대한 변화로서 실제 기하 정확도나 world 거리의 오차가 아니다. 모든 mask union 군에는 camera0 책상 false positive와 camera2의 다른 면이 포함될 수 있어 별도 강제 진단군으로 구분한다.

사전에 고정한 top-middle ROI(처리좌표 x=[154,358), y=[0,96))에서 camera0 17,640점·camera1 8,751점을 모두 이동했다. 해당 ROI의 최대 자기 깊이 변화는 각각 72.50%·70.11%다. 번호 혼동을 피하도록 두 카메라를 모두 기록했다. ROI와 SAM의 교집합이며 수동 벽 GT annotation은 아니다.

주 군의 고정 벽 두께는 C3a 대비 약 24.37% 감소하고 source median 층 간격은 약 11.66% 감소했다. 수용점의 실제 공유 평면 잔차는 1e-9 이내이며 확대 단면에서 기존 잔여 굴곡이 제거된 모습을 확인했다. 기존 고정 벽 ROI의 source0/1 외 다른 부분에서 큰 이동이 발생하므로 이 두 수치만으로 전체 효과를 대표하지 않는다. 전체 GT 정확도는 여전히 미평가다.

6군 모두 점 수·RGB·ID·K/pose·거절점 불변, H4e 제어 bitwise 재현, 5⊆20⊆uncapped 단조성·공통점 XYZ 동일성, 수치 교차 검사 및 기존 가시성 조건을 통과했고 retained=proposed다. 법선·거리·move를 다시 적용하는 숨은 gate는 없다. 음의 깊이 또는 평행 광선은 수용하지 않았다. 실제 제안점군은 각 군의 proposed에 보존했다.
