# 보조 검증·실행 명세

실행 실패·설계 보완은 원본을 덮어쓰지 않는다. 각 실행 source snapshot과 config가 당시 명세다.

## C0a — 최근접점 보조 지표

C0 최초 실행에서 OpenCV FLANN KD-tree의 checks=-1 결과가 exhaustive 정답과 달랐다. C0a에서 재현하고 정확한 BF L2 방식으로 교체했다. 비용을 제한하기 위해 각 source 프레임의 고정 균등 512 query를 상대 프레임 전체 target에 비교한다. float32 검색 결과의 표본 통계이며 전체 source 통계나 물리적 대응 GT가 아니다. 주 FoV 손실의 float64 고정 영상 대응은 이 검색을 사용하지 않는다.

## C0b — 카메라·장면 제어

순수 회전·평면·평행·동일 관측의 실제 역투영 residual rank와 depth-only rank, 대응 부족 거절을 보조 검증했다. 고정 Depth가 있는 이 문제에서 순수 회전/평면이라는 이유만으로 무조건 불가능하다고 판정하지 않는다.

## C1a — 실내 영상 대응 지원 보완

원래 SIFT C1의 고정 유효 대응은 30/11/16개로 지원 조건에 미달했다. 이 결과와 기준은 보존한다. 대체 특징의 효과를 계산하기 전에 다음 두 방법을 고정한다.

1. ORB: nfeatures=8192, fastThreshold=7, 나머지 설치 버전 기본값.
2. AKAZE: threshold=1e-4, 나머지 설치 버전 기본값.

두 방법 모두 Hamming descriptor, 양방향 ratio 0.75·상호 일치, 같은 F-RANSAC·Depth/confidence gate·track split·지원 기준을 적용한다. ORB→AKAZE 순서에서 **처음 지원 조건을 통과한 방법**만 보완 실험 입력으로 선택하며 기하/validation/GT 점수로 고르지 않는다. 둘 다 실패하면 실제 지원 부족으로 남긴다. 이 사후 보완은 원래 SIFT 계획과 구분한 탐색적 amendment다.

## C2a/C3a — 저지원 조건의 탐색적 수치 진단

C1a의 ORB/AKAZE도 모든 쌍의 지원 기준을 통과하지 못했다. 원래 C2/C3는 지원 부족 gate를 유지하며 β=1을 보존한다. 실제 FoV 변경 시 수치 반응을 확인하기 위한 별도 C2a/C3a에서는 **원래 C1의 SIFT 대응과 고정 split을 그대로** 사용해 1변수/6변수 fit을 시도한다. 새 대응·임계값·FoV 범위·손실 가중치를 고르지 않는다.

이 보조 실행은 rank가 충분할 때만 실시하고 `LOW_SUPPORT_DIAGNOSTIC_ONLY`로 고정 판정한다. 효과 성공이나 검증된 카메라 보정으로 승격하지 않는다. validation이 쌍별 1~6개뿐이라는 한계를 수치와 함께 남긴다. 원래 C3 지원 조건을 통과하지 않은 계수는 주 C5의 보정 입력에 사용하지 않는다. 드론 C4에는 이 지원 gate override를 적용하지 않는다.

## C4a/C5b — coverage를 보존하는 후보의 보조 비교

HKairport01 원래 C4의 6변수 solver 제안은 한 방향에서 초기 관측의 0.5505%를 화면 밖으로 보내 0.5% 기준을 넘었다. 원래 정책은 저장된 IRLS 후보만 검사해 초기값을 선택했다. 이 결과는 보존한다. 기준을 완화하지 않고 초기값과 제안 사이에 유효한 후보가 있는지 확인하기 위해 **효과를 계산하기 전에** 다음 보조 절차를 정한다.

- C4a: 원래 대응·split·FoV 범위·prior·solver를 유지하고, 초기값→solver 제안의 선분을 α=0,1/16,…,1의 17개 고정 값으로 추가 평가한다. 선택은 fit 목적함수와 원래 coverage 기준만 사용한다. 양 드론 샘플에 같은 절차를 적용한다.
- 원래 C4의 validation 결과를 이미 본 뒤 추가한 절차이므로 탐색적 amendment로 표시한다. 이것을 독립적인 확인 실험이라고 부르지 않는다. validation/GT로 α를 선택하거나 구간을 세분화하지 않는다.
- C5는 원래 C3/C4 선택값을 그대로 사용한다. C4a의 계수로 한 융합은 별도 C5b로 저장하며, 같은 색 30·깊이 3% 조건을 사용한다. 두 융합 결과를 함께 보존하고 유리한 결과로 원래 결과를 대체하지 않는다.
