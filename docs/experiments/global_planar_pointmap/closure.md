# VGGT-Ω pointmap·FoV·평면 보정 실험 종료 결론

**종료일: 2026-11-14 · 최종 판정: 실패 — 일반화 가능한 정확도 또는 점군 축소 이득을 입증하지 못함.**

계획된 실행과 후속 진단을 종료한다. 개별 stage의 실행 완료나 기술 검증 통과는 연구 가설의 성공을 뜻하지 않는다. 현재 결과로 자동 평면 보정이 pointmap 정확도나 전체 SLAM 성능을 높인다고 결론 내릴 수 없다.

## 실패 판정 근거

- TUM `freiburg1_desk`와 추가 구간에서 전체 자동 평면 파이프라인 I0–I9를 실행했다. 주 자동 결과 A4는 두 구간 모두 가시성 보존 기준을 통과하지 못해 최종 선택이 `retained=initial`이었다. 당시 평면 소속·구조 정확도를 평가할 GT도 없었다.
- ETH3D office/pipes 레이저 GT 평가에서 거리·법선 RGB 최적화의 깊이 MAE는 각각 초기 1.3286→2.1235cm, 2.2731→2.4325cm였다. pipes의 고정 평면은 2.2031cm로 조금 낮았지만 사전 전체 성공 기준을 충족하지 못했고, 두 장면 모두 최종 이득이 확인되지 않았다.
- 야외 KITTI city와 ETH3D forest의 I26은 `INSUFFICIENT_SUPPORT`였다. FoV focal 오차는 KITTI에서 1.8617→3.5132%로 악화하고 forest에서 7.2131→4.4395%로 감소했다. 숲에는 허용 named 평면 anchor가 없었고 두 장면 모두 RGB 최적화 평면이 0개라 평면 최적화 효과를 검증하지 못했다.
- 별도 C5 색·깊이 점군 축소 실험은 세 장면에서 압축 기준을 통과하지 못했다. 일부 내부 3D 개선이나 한 장면의 고정 평면 개선을 전체 정확도·SLAM 성능 향상으로 확대하지 않는다.
- 블러 개입은 ETH3D office/pipes에서 Omega 깊이 오차를 키우는 효과를 보였지만, TUM의 큰 3D 오차나 모든 FoV 악화를 설명하지 못했다. 이는 유효한 제한적 관찰이며 자동 평면 보정 목표의 성공 근거는 아니다.

## 종료 범위와 보존

계획·데이터 확보·실행·실패·보조 진단의 기록과 산출물은 유지한다. 실패한 실행과 낮은 지원의 결과도 삭제하거나 성공으로 재분류하지 않는다. 이 결론은 이 저장소의 현재 데이터·설정·사전 기준 아래에서 수행한 실험 묶음에 한정되며, 모든 평면 보정 방법의 불가능성을 주장하지 않는다.

추가 실험은 이번 연구 묶음의 범위 밖으로 두고, 재개 여부는 별도 목표와 사전 등록된 성공 기준으로 새로 결정한다.
