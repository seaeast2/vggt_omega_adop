# E0b 중간 기록

- 실행 전 등록: E0 원본, 예측 카메라 고정, 0→1→2 순서.
- 다음 픽셀에 투영되는 이전 지도 점의 Z와 새 관측 Z를 현재 점당 동일 가중치로 평균한다. 새 픽셀 시선의 점 하나로 치환하고 이전 대응점은 삭제한다. 투영되지 않은 점은 유지한다.
- 깊이/법선/가림 gate·GT·최적화는 사용하지 않는다. owner 색상과 원본 출처 혼합색, 중간 지도와 원본 관측의 CSR 출처를 보존한다.

- 실행 완료: 0→1에서 이전 대표점 126,056개를 삭제/치환하고 267,160점을 남겼다. 1→2에서는 이전 대표점 122,443개를 삭제/치환해 최종 341,325점을 남겼다.
- 원본 관측 589,824개는 모두 정확히 하나의 최종 점으로 연결된다. 원본 관측 수 기준 가중치는 사용하지 않고 현재 대표점당 동일 가중치를 적용했다.
- 알려진 깊이 평균·픽셀 시선·삭제 인덱스·비중첩 보존·CSR 분할·PLY/NPZ/PNG 재로딩·부모 해시 불변 검증을 통과했다.
- 전후 투영 패널을 직접 확인했다. 마지막 카메라의 단일 owner 색은 정의상 치환 결과다. 앞선 카메라 0/1의 coverage 감소와 큰 점 변위도 보고서에 기록한다.
- 코드·설정·보고서·소규모 그림을 커밋·푸시하고 원격 SHA를 확인한다. 대용량 PLY/NPZ와 중간 지도는 로컬에 보존한다.
