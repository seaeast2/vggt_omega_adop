# E1 중간 기록

1. E0 완료 Manifest와 전체 산출물 해시를 검증했다.
2. F0 원본 589,824점 NPZ/PLY를 바이트 동일하게 보존했다.
3. 사전 고정 edge/disagreement·호환·voxel 조건으로 6개 방향 깊이 잔차와 층 퍼짐을 측정했다.
4. Voxel 크기·origin에 따른 다중 프레임 co-occupancy 민감도를 기록했다.
5. 호스트 GPU에서 전체/자기 관측/다른 관측의 9회 렌더링을 수행했다.
6. 고정 all 및 공통 마스크로 RGB 지표와 coverage를 분리했다.
7. 알려진 두 층과 저장 마스크·지표 재계산 검사를 통과했다.
8. 원본과 평가 마스크를 E2 인계용으로 고정하고 보고·커밋·푸시한다.
