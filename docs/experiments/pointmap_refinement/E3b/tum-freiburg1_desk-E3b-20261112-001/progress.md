# E3b 중간 기록

- 실행 전 등록: E0/E0b/E3 selected/E3 last의 기존 결과를 비교한다. 새 학습은 하지 않는다.
- 주 지표는 기존 E3 스케일·초기 GT 고정 영역을 사용한 결과별 누락/coverage 및 네 방법 공통 픽셀의 RMSE/AbsRel이다. 결과별 재스케일·GT 모델 선택은 없다.
- 기존 E3 native 깊이·평가 재현, selected=초기 좌표 일치, 원본 출처 매핑을 검증하고 같은 팔레트 PLY·카메라별 출처/깊이/오차 그림을 저장한다.

- 실행 완료: E3 selected=step 0 좌표를 확인했고, last에서 65,010개 점이 이동했음을 재확인했다. 모든 방법의 원본 관측 589,824개 출처 매핑을 검증했다.
- 기존 E3의 native 깊이 배열이 캐시와 정확히 일치했다. 기존 439,400픽셀 RMSE/AbsRel도 1e-12 이내로 재현했다.
- 단일 스케일 1.3228912022012644m/model-unit을 유지했다. 새 공통 영역은 416,835픽셀, 초기 GT 고정 영역은 448,144픽셀이다.
- E0b RMSE/AbsRel은 0.144257m/3.3682%, E3 selected는 0.159963m/3.5912%, E3 last는 0.160427m/3.7590%다. E0b 고정 영역 coverage는 94.897%로 E3 selected 100%보다 낮다.
- PLY·깊이 NPZ·PNG 재로딩, 부모 해시 불변 검증을 통과했다. 깊이·오차·출처 패널 3종을 열어 비교 범위·행/열과 누락 표시를 확인했다.
- 코드·설정·보고서·소규모 그림을 커밋·푸시하고 원격 SHA를 확인한다. PLY/대용량 버퍼는 로컬에 보존한다.
