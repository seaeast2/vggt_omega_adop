# E3b 중간 기록

- 사용자 요청에 따라 비교만 수행한 기존 E3b 코드·보고서·로컬 run `...-001`을 삭제했다. 삭제 전 커밋은 `6de932f167f577ddcb7b7b500412da53eb69444e`이며 새 실행은 `...-002`다.
- E0b 좌표·원본 관측 CSR·최신 owner를 유지한 채 기존 E3와 같은 Photo-only Ray-depth 미분 이동을 적용한다.
- 카메라·점 수·관측 그룹·원본 관측 median RGB는 고정한다. PLY는 프레임 팔레트로 표시한다.
- 학습 중 GT 접근과 GT 체크포인트 선택은 없으며, 학습 후 초기 E0b 기준 단일 스케일·공통 픽셀로 전후 GT 깊이를 평가한다.

- 준비 완료: E0b 341,325점의 좌표·CSR와 초기 점군이 정확히 일치했다. 171,466개 다중 출처 점 중 135,193개가 학습 조건을 통과했고 206,132개는 고정했다.
- 호스트 RTX 5060에서 샌드박스 밖 GPU로 200회 RGB 역전파를 실행했다. 비영 유한 Gradient와 실제 좌표 이동을 확인했고, 마지막 상태에서 126,222개가 1e-8 모델 단위보다 크게 이동했다.
- 손실은 0.059157045→0.209851931로 악화했다. 평가한 11개 체크포인트 중 selected는 step 0이며 초기 E0b와 좌표가 정확히 같다. 실제 이동된 last를 별도 보존했다.
- 초기에서만 맞춘 GT scale=1.3171403295592672m/model-unit, 공통 402,577픽셀에서 RMSE는 0.146852→0.147653m, AbsRel은 3.374634→3.653819%다. 고정 초기 영역 coverage도 last에서 94.651%로 감소했다.
- 실제 초기 Adam 방향의 Autograd 미분은 음수였지만 전체 렌더 유한차분은 양수였다. Hard visibility/stencil·수치 정밀도의 영향을 분리할 필요를 기록했다.
- 초기/selected/last PLY·NPZ, 11개 체크포인트, RGB·출처 진단 패널, 학습·GT·변위·검증 기록을 보존했다. 효과는 실패로 기록하고 코드·보고서·소규모 그림을 커밋·푸시한다.
