# P2b 중간 기록

- E3b에 저장된 E0b 초기 RGB/alpha 버퍼만 사용해 기하 변화 없이 alpha 곱을 제거한 색상을 비교한다.
- P2 default와 E3b 원본은 변경하지 않는다. 새 미분 최적화·GT 평가는 하지 않는다.
- 같은 E1/학습 마스크의 점수와 탐색적 밝기/alpha 프로브를 기록한다. 원인 분리 그림이며 기하 개선으로 해석하지 않는다.

- 실행 완료: 기존 RGB를 alpha로 나눈 진단에서 밝은 참고 영상의 어두운 픽셀 프로브는 3,366→432개로 줄었다. 해당 초기 픽셀 alpha 중앙값은 Camera 0/1/2에서 0.02295/0.02421/0.00766이다.
- 원본 RGB·alpha·마스크 해시는 유지했고 재합성이 원본 저장 RGB와 일치했다. PNG/NPZ 재로딩을 통과했으며 패널을 직접 확인했다.
- 초기 어두운 픽셀 중 학습 마스크 안은 207개뿐이다. 초기 검은 띠 감소를 E3b 최적화 실패 전체의 원인 규명이나 Gradient 수정 완료로 확대하지 않는다.
- 코드·설정·보고서·진단 그림을 커밋·푸시한다. 기존 P2 default와 E3b 원본은 유지한다.
