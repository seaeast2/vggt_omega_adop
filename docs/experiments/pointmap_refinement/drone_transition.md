HKairport01을 우선 후보로 두고 AMtown01도 같은 방법의 다른 dataset Run ID로 분리한다. 실제 선택 프레임·시간 간격·장면·전처리·입력 해시는 실행 전에 고정한다. 과거 다른 저장소에서 사용한 `[50,70,90,110]`은 참고 이력이며 현재 입력과 동일하다고 가정하지 않는다. 서로 다른 시점의 중첩과 카메라 이동을 확인하되 모델이 예측한 시차를 실제 시차 GT로 부르지 않는다.

두 모델의 과거 PLY와 결과를 현재 Omega 추론으로 대체하거나 섞지 않는다. 각 새 실행에 원본 영상·모델/체크포인트 버전·추론 결과·관측 CSR·실행 코드·카메라별 초기/선택/last·PLY·로그·Manifest를 보존한다. GPU는 샌드박스 밖 호스트에서 실행한다. 완료된 각 실험은 커밋·푸시하고 원격 SHA를 확인한다.

GT가 있으면 출처·보정·유효 영역을 먼저 검증하고 사후 기하 평가를 한다. GT가 없으면 고정 RGB 손실·coverage·원본 해상도 경계/겹침·점 변위를 보고하며, 광도 개선을 실제 3D 정확도 개선으로 판정하지 않는다. 사용 가능하다면 충분한 독립 관측을 가진 구간을 고정해 별도 검증하지만, 동일 공동 추론에 사용한 영상을 독립 held-out이라고 부르지 않는다.
