# C3a FoV 기준선에 PlanarGS의 분할·평면 보정 원리를 적용하는 실험 계획

> 작성일: 2026-11-13<br>
> 상태: **계획 작성 완료 · H0~H6 미착수**<br>
> 연구 용도: 대학원 졸업논문 실험<br>
> 실험 계열: `c3a_plane_refinement`, 코드 `H0`~`H6`<br>
> 목표: **C3a로 프레임 간 정렬을 마친 점군에서, 영상 분할과 공유 평면 재투영이 벽의 잔여 굴곡·층 분리를 줄이는지 확인한다.**

## 1. 범위와 연구 질문

사용자의 최신 지시에 따라 이번 실험은 **점군 기반 분할·평면 적합·재투영**으로 한정한다. 추가 RGB 손실 학습, 색 변경, 카메라 재최적화, 점 추가·삭제·융합은 하지 않는다. 기존 E/C/G/V 실행과 결과를 보존한다.

사용자는 G 일부 결과에서도 벽의 겹침 개선을 확인했다. 그 관찰을 부정하지 않으며, 이번에는 효과를 분리하기 위해 **G 결과를 초기값으로 쓰지 않고 C3a FoV 보정 결과 하나만 고정**한다.

[PlanarGS 조사 문서](research/planargs_reuse_review.md)에서 확인한 영상 후보 검출·분할, 시점 간 후보 전달, 법선·거리 기반 마스크 정제, 평면과 픽셀 광선의 교차 깊이 계산을 참고한다. **원논문 전체 재현이 아니라 해당 원리를 C3a pointmap에 이식하는 실험**이다. 공유 평면 ID·robust 적합·이동 제한은 자체 설계로 구분한다.

연구 질문:

1. 영상 마스크가 기하만 사용한 평면 후보보다 벽과 주변 물체를 잘 구분하는가?
2. 원시 분할 마스크에 기하 정제를 추가하면 잘못된 평면 보정을 줄이는가?
3. 프레임마다 독립적으로 평평하게 만드는 것보다 **같은 벽의 공유 평면**으로 이동하는 것이 층 분리를 줄이는가?
4. 평면에 완전히 재투영하는 방법과 원래 깊이를 보존하는 soft 보정은 어떤 차이가 있는가?
5. 점·색·카메라를 보존하면서 벽 개선과 물체 경계·가시성 보존을 함께 달성할 수 있는가?

## 2. 고정 기준선: C3a의 실제 FoV 제안값

기준 실행은 `tum-freiburg1_desk-C3a-20261112-001`이다. 사용자가 육안으로 좋은 정합을 관찰한 파일은 자동 선택 결과가 아니라 다음의 **실제 제안값**이다.

## 4. 비교군: 분할·정제·공유 효과를 분리

| 비교군 | 평면 후보 | 적합 단위 | 보정 |
| --- | --- | --- | --- |
| **A0_C3a** | 없음 | 없음 | C3a 그대로 |
| **A1_FRAME_RAWMASK** | H1 원시 영상 마스크 | 프레임별 독립 평면 | hard 재투영 |
| **A2_FRAME_REFINED** | H2 기하 정제 영상 마스크 | 프레임별 독립 평면 | hard 재투영 |
| **A3_SHARED_RAWMASK** | H1과 같은 원시 마스크 | 여러 프레임의 공유 평면 | hard 재투영 |
| **A4_SHARED_REFINED** | H2와 같은 정제 마스크 | 여러 프레임의 공유 평면 | hard 재투영 · 주 비교군 |
| **A5_SHARED_SOFT** | A4와 동일 | A4의 평면·지지점 동결 | 원래 깊이 보존 soft 보정 |
| **A6_GEOMETRY_ONLY** | 영상 분할 없는 3D 영역 검출 | 여러 프레임의 공유 평면 | hard 재투영 |

A1↔A2, A3↔A4는 마스크 정제 효과, A1↔A3와 A2↔A4는 공유 평면 효과다. A4↔A5는 깊이 보존 효과다. A4↔A6는 영상 분할 추가의 전체 효과이며, 서로 다른 후보 집합을 가진다는 점을 표기한다. 두 집합의 교집합·전체 고정 평가 영역을 모두 보고한다.

**H3와 H4는 같은 robust 적합기를 사용한다.** 공유 여부와 적합기 변경 효과를 섞지 않는다. 원래 코드의 plain least-squares 계산을 확인하는 제어가 필요하면 H3a로 별도 분리한다.

## 5. H1: 영상 분할

조사한 공식 코드 commit은 `a68f22043e95146c4f1c52cc0e471a6a90e86f73`다. 모델 checkpoint·소스 revision·실제 라이브러리 버전은 H1에서 별도로 고정·해시 검증한다. [조사 소스 manifest](research/planargs_source_manifest.json)

- 주 실험은 공식 LP3와 같은 **GroundingDINO + SAM ViT-H** 조합, text prompt `wall.`로 제한한다. 책상·모니터 등 다른 평면은 이번 주 평가 대상에 추가하지 않는다.
- detector 기본값 box score 0.25, text score 0.2, SAM box prompt와 `multimask_output=False`를 출발 설정으로 고정한다. score를 평면성 확률로 해석하지 않는다.
- 원본 RGB에서 마스크를 만들고 처리 격자로 label을 옮길 때 resize/crop 변환을 명시한다. mask resize는 nearest-neighbor다.
- 원시 마스크는 pointmap 결과를 보고 수정하지 않는다. RGB overlay로 누락·물체 포함·두 벽의 혼합을 확인하고 기록한다.
- 자동 검출이 벽을 놓치면 그 결과를 보존한다. 점/박스 수동 prompt의 SAM 비교는 **H1a**로 분리하며, prompt 좌표·검토자·수정 이력을 기록한다. 자동 군의 성공처럼 합산하지 않는다.
- 마스크와 임베딩 등 반복에 필요한 결과를 캐시한다. H3~H5의 후보마다 모델을 다시 실행하지 않는다.

시점 간 후보 전달은 H1b 보조 검증으로 분리할 수 있다. 직전 프레임의 큰 마스크 3개를 A0 depth/K/pose로 투영해 박스를 보완하는 공식 아이디어를 따르되, 주 mask 결과를 사후 덮어쓰지 않는다. 이 전달은 검출 보완이지 공유 3D 평면 판정이 아니다.

## 6. H2: 구불구불한 벽의 후보 정제

### 6.1 공식 원리와 자체 설정을 분리

PlanarGS의 `NormalSplit`은 법선 표현을 기본 5개 cluster로 분리하고 연결 성분·겹침을 정리한다. 이를 참고하되 마스크 내부의 모든 점이 같은 평면이라고 가정하지 않는다. [공식 마스크 정제 코드](https://github.com/SJTU-ViSYS-team/PlanarGS/blob/a68f22043e95146c4f1c52cc0e471a6a90e86f73/lp3/mask_refine.py)

공식 `dis_thresh=0.05`는 거리 map의 min/max 정규화에 대한 값이고, 5cm나 Z-depth 5%가 아니다. `co_planar`의 0.01도 정칙화 계수다. 이를 우리 평면 inlier 임계값으로 사용하지 않는다. 공식 경로를 비교할 경우 H2a에 별도 저장한다.

### 6.2 주 후보 생성 규칙

다음은 **우리 실험의 사전 기본값**이다. 문헌의 보편적인 평면 판정 기준으로 인용하지 않는다.

- A0의 카메라별 XYZ에서 7×7 픽셀 이웃 PCA로 법선을 구한다. finite·positive와 원본 confidence 하위 10% 제외를 지지점 규칙으로 둔다. 제외점도 최종 점군에서는 삭제하지 않는다.
- 21×21 이웃 법선은 민감도 진단에만 사용한다. 완만한 깊이 굴곡을 작은 이웃 법선만으로 곡면으로 확정하지 않는다.
- 원시 마스크의 3 pixel 경계와 영상 바깥 8 pixel은 기본 보정 대상에서 제외한다. 두 처리는 서로 다른 마스크로 저장한다.
- seed 0, K-means 5개 cluster·10회 반복을 법선 후보 분리의 출발점으로 사용한다. 후보별 연결 성분을 분리하고 이후 robust 평면 잔차로 확인한다. cluster 수를 평면의 정답 개수로 간주하지 않는다.
- 주 후보의 최소 영역은 처리 영상 면적의 0.5%, 적합에 필요한 fit 관측은 프레임당 최소 100개로 둔다. 실제 pixel 수와 4×4 격자 점유 분포를 보고한다.
- 영상 분할이 없는 A6는 같은 A0 법선·confidence와 공간 이웃에서 시작한다. 7×7 인접 영역의 법선 15°와 아래 평면 거리 기준으로 region growing하고 같은 최소 면적·support 규칙을 적용한다. 의미론적으로 벽인지는 보정 전 RGB overlay에서 별도로 표시한다.

각 후보에는 `(frame_id, local_mask_id, original_observation_ids)`를 저장한다. 서로 다른 후보가 같은 관측을 중복 보정하지 않도록 충돌을 해결하고, 모호한 관측은 A0 그대로 유지한다.

### 6.3 적합·검증 분리와 ROI

평면 적합 전에 후보 픽셀을 16×12 타일로 묶고, `SHA256(seed=0, frame_id, tile)` 기준으로 약 80% fit / 20% holdout을 고정한다. 알고 있는 점 대응 track의 보류 관측 주변 3 pixel은 fit에서 제외하고, 같은 알려진 track을 양쪽 split에 넣지 않는다. 각 프레임의 같은 물리 영역이 모든 경우 연결되는 것은 아니므로 완전히 독립적인 표면 검증이라고 부르지 않는다.

벽 내부·물체 경계·비대상 영역의 RGB ROI는 **보정 결과를 보기 전에** 동결한다. G6의 기존 벽 ROI도 별도 참고로 유지하고, 새 ROI는 새 평가라는 점을 명시한다. 각 ROI의 source별 관측 수를 보고하며, 프레임 2의 지지가 없으면 세 프레임 벽 검증으로 표현하지 않는다.

holdout 평면 잔차는 보정 전 후보 평면의 설명력을 검사하는 값이다. holdout 점까지 그 평면에 옮긴 뒤 잔차가 0이 된 결과를 정확도 개선 증거로 사용하지 않는다.

## 7. H3/H4: 동일 적합기와 공유 평면 연결

### 7.1 평면 적합

단위 법선의 일반형 `nᵀX+d=0`을 사용한다. seed 0의 RANSAC 최대 2,000회로 초기 후보를 얻고 SVD와 Huber IRLS 최대 20회로 재적합한다. 프레임별 적합도 같은 방법을 사용한다.

기본 inlier 기준은 **점–평면 수직 거리 / 원본 자기 Z-depth ≤0.005**다. Huber 전환값도 이 정규화 기준의 0.005로 두며 분모는 A0에서 고정한다. 소속 후보의 fit 관측 중 최소 70%와 최소 100개가 지지해야 한다. 국소 법선 15°는 후보 연결에 사용하되 최종 적합 지원 수와 잔차를 함께 확인한다.

공유 평면에서는 프레임별 합계 가중치를 같게 두어 한 프레임의 조밀한 점이 지배하지 않게 한다. 거의 선형으로만 분포한 점, 공간 분포가 부족한 후보는 `DEGENERATE_PLANE_SUPPORT`로 보존한다. SVD 고유값과 공간 범위를 H0 합성 기준과 함께 기록한다.

### 7.2 공유 평면 association

항상 **보정 전 A0**와 동결된 후보로 연결을 판단한다.

1. 후보 점을 타 카메라에 양방향 투영해 양의 Z·화면 내부·target 후보 overlap을 확인한다.
2. 투영 후 target depth와 비교하고 상대 Z 차이 3% 이내인 지지만 사용한다. 앞의 물체 뒤에 있는 점 등 가림 거절을 구분한다. 두 depth가 모두 예측치이므로 이 gate는 참 대응의 보장이 아니다.
3. 각 방향의 유효 지지 최소 100 pixel, target 후보 안에 들어오는 비율 최소 20%, 법선 차이 ≤15°를 기본 연결 기준으로 둔다.
4. 두 후보 centroid를 **서로의 평면에 대입한 거리**가 각각 기준 Z의 1% 이내여야 한다. 비평행한 평면의 offset 숫자만 직접 비교하지 않는다.
5. 제안 그룹의 모든 후보와 모든 구성 프레임을 다시 검사하고, 공동 적합 후 각 프레임 support 조건을 요구한다. A↔B와 B↔C만 맞는다는 이유로 A/B/C 전체를 연쇄 병합하지 않는다.

최소 두 프레임이 지지한 경우에만 `shared_plane_id`를 만든다. 연결되지 않은 단독 후보는 H3에는 사용할 수 있지만 H4/H5에서는 A0 좌표를 유지한다. 수용·거절·모호 상태와 근거를 JSON 및 overlay로 저장한다.

A3/A4/A6의 association은 같은 규칙을 사용하지만 후보는 다르다. A4에서 얻은 mask·공유 ID·평면을 A5에 그대로 전달하며 결과를 보고 다시 병합하지 않는다.

## 8. 점 이동: hard와 soft 재투영

C3a의 K/R/t/C를 고정하고 `r=K⁻¹[u,v,1]ᵀ`, `q=R⁻¹r`로 둔다.

```text
X0 = C + D0*q
공유 평면: nᵀX+d=0, ||n||=1
Dplane = -(nᵀC+d)/(nᵀq)
Xplane = C + Dplane*q
```

이 식은 PlanarGS의 평면 깊이 계산 원리를 월드 좌표 공유 평면으로 확장한 자체 설계다. 픽셀 광선의 세 번째 카메라 성분이 1이므로 D는 광선 길이가 아닌 Z-depth다.

이동 전 gate:

- 모든 값이 finite이고 Dplane>0.
- `abs(nᵀ q/||q||) ≥0.2`로 스침각 교차를 제한.
- `abs(Dplane-D0)/D0 ≤0.02`로 최대 상대 깊이 이동 제한.
- 후보 경계·충돌·비대상·낮은 지지 관측은 이동하지 않음.

gate는 **hard 교차 목표**로 한 번 판정해 A4/A5에 공통 적용한다. 거절된 점을 삭제하거나 soft 방식에서 조용히 다시 수용하지 않는다.

H3/H4의 hard 방식은 Dnew=Dplane이다. H5는 같은 고정 평면에 대해 다음 작은 문제를 사용한다.

```text
min_D  ((nᵀ(C+D*q)+d)/D0)^2 + ((D-D0)/D0)^2
Dsoft = D0 + α*(Dplane-D0)
α = (nᵀq)^2 / (1 + (nᵀq)^2)
```

이는 공면성과 원래 깊이 보존을 결합한 **자체 quadratic surrogate**이며 원논문의 손실 전체와 같다고 주장하지 않는다. 별도 학습 없이 닫힌 형태로 계산하고 H0에서 독립적인 수치해와 비교한다. hard/soft 모두 원본 RGB·ID를 유지한다.

H4a 민감도 검증이 필요하면 inlier 거리 0.25%/0.5%/1%, 최대 이동 1%/2%/5%를 **한 번에 한 항씩** 변경한다. primary 설정을 validation·육안 결과로 교체하지 않고 각각 별도 run으로 보존한다.

## 9. H0 기술 검증과 종료 조건

필수 검사:

1. C3a 원본 NPZ 재역투영이 보존 XYZ와 `atol=1e-8, rtol=1e-8` 이내로 일치하는지 확인한다. float32 변환 차이가 있으면 별도 보고한다.
2. 알려진 평면에 속한 합성 depth에서 교차식·hard 결과를 확인한다. 자기 카메라 재투영 오차 `<1e-5 pixel`을 요구한다.
3. soft 닫힌 해와 독립적인 1차원 수치 최소화의 상대 차이 `<1e-8`을 검사한다.
4. 두 평행한 다른 벽, 모서리의 두 면, 곡면, 가림, 한 프레임만의 지지, 거의 선형인 지지점, 스침각·음의 깊이·2% 이동 경계의 제어를 확인한다.
5. 원본 RGB·K·pose·점 ID·전체 점 수 불변을 배열 단위로 검증한다. 비대상·거절점 XYZ는 bitwise 동일해야 한다.
6. 합성 다중 프레임 굴곡+offset 제어에서 독립 평면은 평평해도 층이 남을 수 있고 공유 평면은 수용점의 층을 줄이는지 확인한다. 결과가 한 평면이 되었다는 사실 자체와 실제 정답 평면 복구는 나눠 평가한다.

모델 설치·접근 문제는 구체적인 오류와 시도 결과를 기록한다. 다른 모델이나 입력을 임의로 대체하지 않는다. 지원 부족이면 `LOW_SUPPORT_DIAGNOSTIC_ONLY`, 평면/연결 실패면 `NO_VALID_PLANE`/`NO_SHARED_PLANE`, 기술 불일치면 `TECHNICAL_CHECK_FAILED`로 구분한다.

## 10. 평가: 깔끔함·정합성·실제 정확도를 분리

모든 수치는 A0 대비로 비교하고 프레임·공유 plane·카메라 방향별 값을 남긴다.

| 평가 | 내용과 한계 |
| --- | --- |
| 국소 벽 형태 | 고정 관측 ID·고정 A0 기준 평면에서 source별 signed-distance median, 층 간격, p95-p05 두께, 잔여 굴곡. 적합에 쓴 평면으로 다시 재평가한 값은 별도 표시 |
| 프레임 간 정합 | 기존 고정 대응점의 3D·양방향 Z·픽셀 재투영 오차. 전체/보정 영역/비대상 영역을 분리 |
| 이동·경계 보존 | 이동 비율·상대 Z 변화 median/p95/max, 마스크 경계 주변 변화, 거절점 수·이유 |
| 가시성 | A0 고정 유효 관측의 frustum 유지율, 고정 K에서의 실제 픽셀 coverage·빈 픽셀. 두 coverage를 구분 |
| 영상 분할 기여 | 동일 고정 ROI에서 적용 면적, 잘못 포함된 물체·누락, 후보 수·성공 공유 plane 수. 정답 annotation 없이는 segmentation 정확도로 부르지 않음 |
| 비용 | 모델 준비/분할/정제/연결/적합/재투영을 나눠 시간·peak memory·저장 크기 측정 |
| 실제 정확도 | TUM depth/pose/K·시간 동기·resize/crop 검증이 완료된 경우에만 GT 평가. A0에서 정한 정렬·scale·마스크를 전 후보에 고정 |

사전 판정은 다음을 함께 보고한다.

- **평면 정리 관찰:** 고정 벽 ROI의 층 간격과 p95-p05 두께 각각 ≥20% 감소. A0 값이 너무 작으면 상대 개선 대신 절대 차이를 제시한다.
- **보존 조건:** 점 수·색·ID·카메라 불변 통과, 비대상 XYZ 불변, 모든 방향의 A0 대비 frustum 손실 ≤0.5 percentage point, 실제 픽셀 coverage 감소 ≤0.5 percentage point.
- **추가 정합 검증:** 고정 보류 대응점의 3D/재투영 오차와 쌍별 변화를 보고한다. median이 1% 넘게 악화하면 상충 표시를 한다. 평면화만 성공했거나 다른 지표와 상충하면 종합 정확도 개선으로 판정하지 않는다.

위 수치는 우리 실험의 사전 기준이며 논문의 보편 기준이 아니다. 실패한 군도 실제 PLY와 후보를 보존한다. 자동 기준에서 거절되었다고 전체 육안 표면이 악화되었다고 단정하지 않는다. GT가 준비되지 않았다면 내부 정합성과 육안 관찰 범위로 결론을 제한한다.

H6는 A0와 모든 군을 같은 점 크기·z-buffer·가림 규칙으로 비교한다. 원본 RGB도 같은 크기·보간법으로 표시한다. 각 카메라의 전체/타 프레임만/출처별 투영, 고정 외부 시점, 벽 단면을 저장한다. 지표·그림·PLY가 동일한 상태를 가리키는지 확인한다.


각 비교군은 `initial/proposed/retained`를 구분한다. proposed는 gate를 거친 실제 보정 결과, retained는 보존 조건을 만족하지 못했을 때 반환할 A0 또는 통과 결과다. 초기 A0로 복귀했는데 보정 성공이라고 표시하지 않는다. proposed가 복귀되어도 PLY·지표·그림은 모두 보존한다. 초기값과 동일한 상태는 그 사실을 명시한다.

NPZ에는 XYZ·Z-depth·원본 ID/RGB/K/pose, local/shared plane ID, 수용·거절 마스크, 원본→보정 관측 대응을 저장한다. PLY는 `pixel_rgb.ply`와 `frame_colors.ply` 두 종류로 내보낸다. 프레임 0/1/2는 빨강/초록/파랑을 사용하고 공유 plane 색은 별도 시각화로 둔다.

한국어 보고서에 입력·코드·checkpoint 해시, seed, 모델 score, mask/fit/holdout/ROI, plane 계수·연결 근거·최종 gate·이동량, 기술 검증·실패·실행 환경을 남긴다. GPU 작업은 사용자 지침에 따라 **샌드박스 밖 호스트**에서 실행하고 CPU 기하 처리와 구분한다.

매 실험 완료 후 코드·설정·경량 중간 결과·보고서를 커밋·푸시하고 원격 반영을 확인한다. 대형 PLY/NPZ·모델은 기존 `.gitignore` 정책을 유지하며 경로·크기·해시를 추적한다. 보조 검증은 H0a/H1a 등으로 구분하고 이전 실행을 덮어쓰지 않는다.

현재는 계획만 작성했다. 모델 설치·추론·새 PLY 생성은 아직 수행하지 않았다.
