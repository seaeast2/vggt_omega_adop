# E0c — E0b 순차 깊이 평균에 원본 RGB 유사도 gate 추가

E0 원본에서 0→1→2를 새로 처리한다. 이미 색이 섞인 E0b 결과를 사후 필터링하지 않는다. 같은 다음 카메라 픽셀로 투영된 이전 대표점 중 색 gate를 통과한 점만 E0b와 같은 Z 산술 평균에 포함하고 삭제/치환한다. 거절된 점과 비투영 점은 정확히 유지한다.

기본 gate는 **그룹의 모든 원본 관측 RGB의 채널별 max−min이 30 이하**다. RGB는 전처리된 원본 E0 관측의 8비트 인코딩 값이며 프레임 팔레트가 아니다. 이전 그룹의 RGB min/max를 추적해 평균색 기반 연쇄 혼합을 막는다. 같은 픽셀의 후보는 target RGB에 대한 최악 채널 차이가 작은 순서, 같은 점수면 현재 점 인덱스 순서로 처리한다. 후보를 추가한 전체 그룹이 gate를 만족해야 하므로 target과 각각 비슷하지만 서로 다른 두 후보를 무조건 함께 합치지 않는다.

```bash
OPENBLAS_NUM_THREADS=2 .venvs/p0-py311/bin/python experiments/pointmap_refinement/E0c/run.py \
  --run-id tum-freiburg1_desk-E0c-20261112-001
```

새 Run ID가 필요하다. 호스트 CPU만 사용한다. threshold=255 제어 실행이 기존 E0b 최종 XYZ/owner/원본 관측 매핑과 정확히 같은지 확인한 뒤 threshold=30을 실행한다. 임계값은 GT 결과를 보고 바꾸지 않는다. 색 경계 30/31, 색 불일치 보존, 같은 픽셀 후보의 상호 색 범위와 기존 그룹 연쇄 혼합 거절을 제어 예제로 검증한다.

최종 PLY는 owner 프레임 색과 원본 출처 혼합색을 따로 저장한다. 실제 원본 RGB min/max/median, 원본 관측→최종 점과 CSR, 중간 승인/거절·치환 인덱스를 NPZ에 보존한다. 최종 CSR를 통해 원본 RGB 범위를 독립 재계산해 gate를 검증한다.

E0/E0b/E0c의 같은 카메라 투영과 GT 깊이를 사후 비교한다. 스케일은 기존 E3b -002의 초기 E0b에서 얻은 한 값만 재사용한다. 원본 E0의 GT 유효 영역에 대한 coverage/누락과 공통 영역의 오차를 나눠 보고한다. 같은 색의 다른 표면은 합쳐질 수 있고, 같은 표면도 조명·노출 차이로 거절될 수 있다. 색 범위 제한 충족이나 점 수 변화 자체는 기하 정확도 증거가 아니다.
