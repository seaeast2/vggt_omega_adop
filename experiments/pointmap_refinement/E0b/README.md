# E0b — 다음 카메라 픽셀의 깊이 평균과 이전 점 치환

E0 원본 3장의 관측과 예측 카메라를 재사용한다. 프레임 순서는 0→1→2다. 새 프레임 j의 픽셀 p에 투영된 현재 지도 점의 카메라 Z를 `z_1...z_m`, 새 관측 깊이를 `D_j(p)`라 하면 다음을 계산한다.

`D_new(p) = (D_j(p) + sum(z_i)) / (1 + m)`

새 프레임의 해당 픽셀 시선 위에 D_new의 점 하나를 만들고, 대응된 이전 지도 점 m개를 삭제한다. 현재 지도 대표점 하나당 가중치는 1이다. 이미 융합된 점을 과거 관측 수로 다시 가중하지 않는다. 투영되지 않은 이전 점과 새 프레임의 비중첩 픽셀은 유지한다. 모델 재추론·학습·Pose 보정·GT 사용은 없다.

```bash
OPENBLAS_NUM_THREADS=2 .venvs/p0-py311/bin/python \
  experiments/pointmap_refinement/E0b/run.py \
  --run-id tum-freiburg1_desk-E0b-20261112-001
```

새 Run ID만 허용한다. 호스트 CPU에서 실행하며, E0/E0a 및 과거 결과는 읽기 전용이다. E0a의 CPU 투영 도우미를 실행 디렉터리에 복사한 뒤 사용한다. 설정·소스 사본·환경·입출력 SHA-256·실행 로그·진행 기록을 독립 보존한다.

`fused_owner_colors.ply`의 frame_id는 점을 최종 보유하는 카메라다. E0a의 원본 출처 frame_id와 의미가 다르다. owner 0/1/2는 빨강/초록/파랑이며, 이전 점을 새 프레임으로 치환하므로 겹침 영역의 색이 최신 프레임으로 바뀌는 것은 정의상 결과다. 같은 좌표의 `fused_source_mix.ply`는 그룹에 포함된 서로 다른 원본 프레임 색을 같은 가중치로 평균한다. 원본 영상 색을 점에 사용하지 않는다.

NPZ에 원본 관측→최종 점 인덱스, CSR 관측 목록, 원본 프레임 비트맵·개수, owner 카메라·픽셀을 저장한다. 0→1 및 1→2 중간 지도·삭제/치환 인덱스·평균 깊이도 보존한다. 모든 원본 관측은 정확히 하나의 최종 대표점으로 추적된다.

연관 기준은 같은 픽셀뿐이며 깊이 차이/법선/가림 gate는 없다. 앞·뒤 물체의 잘못된 합침, 경계 혼합, 픽셀 양자화와 실행 순서 의존성을 허용하는 단순 기준선이다. 감소한 점 수나 단일 층·최신 프레임 색은 기하 정확도 개선 증거가 아니다. GT 정확도·벽 ROI/두께는 평가하지 않는다.
