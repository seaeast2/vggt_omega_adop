# E0a — 프레임 색상으로 보는 원본 점군과 카메라별 투영

E0의 관측·예측 카메라를 읽기 전용으로 재사용한다. Frame 0/1/2를 빨강/초록/파랑으로 바꾸며 XYZ·관측 출처·점 수를 보존한다. E2/E3 점군을 사용하지 않는다.

```bash
.venvs/p0-py311/bin/python experiments/pointmap_refinement/E0a/run.py \
  --run-id tum-freiburg1_desk-E0a-20261112-001
```

새 Run ID만 허용한다. 호스트 CPU 실행이며 GPU를 사용하지 않는다. 원본 512×384 격자의 최근접 픽셀 하나에 점을 투영하고 최소 양수 camera-Z의 출처 색을 표시한다. 검정은 빈 픽셀이다. 정확히 같은 깊이는 낮은 frame_id, 같은 프레임에서는 원본 관측 인덱스를 우선한다. 원본 RGB는 참고 패널에만 사용한다.

- `all`: 전체 점군의 앞면 출처 색상.
- `cross`: 해당 카메라의 자기 프레임 점을 제외한 앞면 출처 색상.
- `source_0/1/2`: 각 출처를 단독으로 투영한 색상. 다른 출처가 가리는 점을 확인한다.
- `near_front_support`: 출처별 front Z가 전체 최소 Z의 3% 이내인 출처들의 RGB를 같은 가중치로 평균한 보조 그림. 빨강+초록은 어두운 노랑, 빨강+파랑은 자홍, 초록+파랑은 청록, 세 출처는 회색이다. 실제 불투명 앞면 영상이나 동일 물리점 대응의 증거가 아니다.

`overview.png`는 카메라별 원본 RGB/all/cross/보조 혼합색, `source_projections.png`는 카메라×출처 격자다. 개별 PNG는 라벨을 삽입하지 않은 원본 격자이며 패널에는 카메라·입력 인덱스를 표시한다. 버퍼 NPZ에 깊이·앞면 출처·원본 관측 인덱스·출처 비트맵을 저장한다.

설정·코드 사본·입출력 SHA-256·진행 로그·환경을 Manifest로 연결한다. PLY/PNG/NPZ를 재로딩하고 XYZ·출처 보존, 앞면 깊이, 자기 투영을 검증한다. 깊이는 모델 단위다. 점 확대/Gaussian/Alpha/Confidence 필터가 없으므로 P2/E1 RGB 렌더러와 같은 영상 지표로 비교하지 않는다. GT 정확도·벽 ROI·표면 두께·최적화 효과는 평가하지 않는다.
